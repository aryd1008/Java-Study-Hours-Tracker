# Java Study Hours Tracker

## About the Project

As a college student, I sometimes find it hard to keep track of how much time I spend studying different subjects. I want to make a simple program that helps students stay organized and understand their study habits better.

## What the First Version Will Do

The first version of my program will let users enter what subject they studied, the date, and how long they studied. It will save their study sessions so they can look back at them later. Users will also be able to see their total study time for the week and how much time they spent on each subject. The program will ask them to try again if they enter something incorrectly.

## Future Plans

Once the basic program is working, I would like to add weekly study goals, graphs that show study progress, and a way to save weekly summaries.

## Tools I Will Use

I will write the program in Java and use Visual Studio Code to work on it. The study information will be kept in a simple CSV file. I will use GitHub to save my work and keep track of the changes I make throughout the project.

## How I Plan to Build It

I will start by making the main menu and letting users enter study sessions. Next, I will work on saving and reading their information. After that, I will add weekly summaries and test the program to make sure everything works.
