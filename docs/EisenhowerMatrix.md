# Eisenhower Matrix — Java Study Hours Tracker

| | **Urgent** | **Not Urgent** |
|---|---|---|
| **Important** | **DO (MVP, Version 1.0)**<br>- Record a subject, date, and study duration.<br>- Save study sessions for later use.<br>- Show weekly total hours and totals by subject.<br>- Check inputs and ask users to correct errors. | **SCHEDULE (Version 2.0+)**<br>- Set weekly study goals for each subject.<br>- Show graphs of study progress over time.<br>- Export a weekly study summary. |
| **Not Important** | **DELEGATE (Use a Java library)**<br>- Use Scanner to read keyboard input.<br>- Use java.time to manage dates and weeks.<br>- Use Java file tools to read and save CSV data. | **DELETE (Leave out)**<br>- Online accounts and password logins.<br>- Sharing study hours with friends.<br>- Social leaderboards and competitions.<br>- A separate mobile app. |

The **Do** quadrant defines the MVP: the smallest complete version of the Study Hours Tracker. The **Schedule** quadrant contains features to consider for Version 2.0 or later.
